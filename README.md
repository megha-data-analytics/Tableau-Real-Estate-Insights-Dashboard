# Real Estate Insights Dashboard – Tableau

## Project Overview
This project analyzes real estate sales data from 2011 to 2022 using Tableau. The dashboard provides insights into property sales, town-wise performance, residential property distribution, sales trends, and sales ratios.

## Tools & Technologies
- Tableau Desktop
- Microsoft Excel
- Data Visualization
- Data Analysis

## Dashboard Features
- Total Sales Amount by Town
- Yearly Sales Trend
- Property Type Distribution
- Average Sales Ratio by Town
- Residential Type Sales Volume
- Sales Distribution Map
- Dynamic Metric Selection (Sale Amount / Assessed Value)
- Interactive Filters for Town, Year, and Property Type

## Dataset
The original Real Estate Sales dataset (2011–2022) is hosted on Google Drive because of its large file size.

- Analyze real estate sales performance.
- Identify top-performing towns.
- Understand property type distribution.
- Track yearly sales trends.
- Support data-driven planning and decision-making.
